# Firmware, split roles, build and flashing

## Roles

The build matrix defines:

| Artifact | Controller role | Host behavior |
| --- | --- | --- |
| `corne_left` | BLE central/master | Connects to macOS and fetches the right battery |
| `corne_right` | BLE peripheral | Connects to the left and sends key/battery events |
| `settings_reset` | Utility image | Clears settings/bonds when recovery is needed |

Only the left central should be paired with macOS. The right peripheral should
be powered, nearby, and paired internally with the left. Connecting a USB cable
to the right does not make it a standalone keyboard.

## Battery and power configuration

`config/corne.conf` enables:

```text
CONFIG_BT_BAS=y
CONFIG_ZMK_BATTERY_REPORTING=y
CONFIG_ZMK_BATTERY_REPORTING_FETCH_MODE_LITHIUM_VOLTAGE=y
CONFIG_ZMK_BATTERY_REPORT_INTERVAL=60
CONFIG_ZMK_SLEEP=n
CONFIG_ZMK_SPLIT_BLE=y
CONFIG_ZMK_SPLIT_BLE_CENTRAL_PERIPHERALS=1
CONFIG_ZMK_SPLIT_BLE_CENTRAL_BATTERY_LEVEL_FETCHING=y
CONFIG_ZMK_SPLIT_BLE_CENTRAL_BATTERY_LEVEL_PROXY=y
```

Deep sleep is intentionally disabled. ZMK idle should preserve Bluetooth
connectivity, but deep sleep disconnects Bluetooth and can require a wakeup
source plus several seconds of reconnection. The current priority is reliable
wake/reconnect over maximum battery life.

## GitHub Actions build

The production build is generated by the existing GitHub Actions workflow. Wait
for the workflow to finish successfully, download the firmware artifact, and
flash matching left/right files from the same workflow run.

Do not mix artifacts from different commits.

## Flashing production firmware

1. Download the artifact for the latest successful workflow run.
2. Put the left nice!nano into UF2 bootloader mode.
3. Copy `corne_left-nice_nano_v2-zmk.uf2` to the mounted UF2 volume.
4. Repeat for the right using `corne_right-nice_nano_v2-zmk.uf2`.
5. Power-cycle both halves and pair only the left central with macOS.

On macOS, Finder can fail with error `-36` while copying UF2 files. Use the
Terminal instead:

```sh
ls /Volumes
cp ~/Downloads/corne_right-nice_nano_v2-zmk.uf2 /Volumes/NICENANO/
sync
diskutil eject /Volumes/NICENANO
```

Use a data-capable USB cable and connect directly to the Mac when possible.
The mounted volume may have a different name; use the name shown by `ls
/Volumes`.

## Settings reset and re-pairing

Use `settings_reset` only when normal flashing does not recover bonds or split
connections. If resetting both halves:

1. flash the `settings_reset` image to the left;
2. wait for it to reboot;
3. flash the same reset image to the right;
4. flash the matching production left and right images;
5. remove the old Corne pairing from macOS;
6. clear the active ZMK Bluetooth profile with the keymap's `BT_CLR` binding;
7. pair the left central again.

The current keymap places `BT_CLR` on the lower layer's first key. Hold the
lower-layer key and press the top-left key.

## Optional debug image

The `battery-debug` snippet is not in the production matrix because it enables
USB logging, debug logging, and a 10-second battery report interval. Use it only
for diagnosis:

```sh
west build -s zmk/app -b nice_nano_v2 -S battery-debug \
  -- -DSHIELD=corne_left -DZMK_CONFIG="$PWD/config"
west build -s zmk/app -b nice_nano_v2 -S battery-debug \
  -- -DSHIELD=corne_right -DZMK_CONFIG="$PWD/config"
```

The log should contain a line similar to:

```text
State of change N from M mv
```

Compare `M` with a multimeter before changing the percentage mapping. See
[Battery model](battery.md).
